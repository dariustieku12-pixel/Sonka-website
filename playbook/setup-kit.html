🎁 The Free Setup Kit

Your $0 toolkit, set up in 60 minutes

Six free accounts, one AI workspace, zero credit cards. Do this once and you're ready to build any app.

This is the prep work. Module 1 of the full $0 App Founder playbook (the rest of which ships in 4 weeks). Tick everything off before you sit down to actually build — you'll save days of setup friction.

1

Install Claude Code

Claude Code is the AI you'll talk to. It runs as a tool you install on your computer (Mac / Windows / Linux) and reads your project files like a developer would.

  1. Open claude.com/code
  2. Sign in with Google or email (creates a free Anthropic account)
  3. Download the installer for your computer (Mac/Windows/Linux)
  4. Open it. It opens inside VS Code (a free code editor — install that too if you don't have it: code.visualstudio.com)
  5. You get free credits to start — enough to build a small real app
Cost: $0 (free tier) · Time: 15 min
2

Create a GitHub account

GitHub stores your app's code online — for free — and is how Claude Code saves your work.

  1. Go to github.com
  2. Click Sign up. Use your real email and a strong password.
  3. Pick a username — this becomes your public profile (github.com/yourname)
  4. Verify email · skip everything optional
Cost: $0 · Time: 5 min
3

Create a Supabase project (your free database)

Supabase is where your app stores users, posts, bookings — everything. Free for the first 500 MB and 50,000 monthly users. Plenty to ship.

  1. Go to supabase.com → Start your project
  2. Sign in with GitHub (one-click using the account you just made)
  3. Click New project. Name it anything. Pick the closest region. Generate a database password and save it somewhere.
  4. Wait 2 minutes for it to provision
Cost: $0 (free tier) · Time: 5 min
4

Create a Railway account (your free server)

Railway hosts the "brain" of your app — the part that handles signups, bookings, payments. Free for 500 hours/month — well above what a new app needs.

  1. Go to railway.app → Login with GitHub
  2. That's it — you get $5 of free monthly credit on the trial plan
Cost: $0 (free tier) · Time: 2 min
5

Create a Higgsfield account (free AI images + videos)

When your app needs photos, ads, or videos, Higgsfield's AI generates them. 10 free credits at signup — enough for ~10 images.

  1. Go to higgsfield.ai → Sign up
  2. Connect with Google or email
  3. Your 10 free credits show in the top right
Cost: $0 · Time: 3 min
6

Get a free domain (optional but recommended)

A real URL like yourapp.com makes everything feel legitimate. There are free options.

  1. Cheapest paid (~$10/year): Namecheap, Porkbun, or Cloudflare Registrar (cheapest, often $7)
  2. Truly free: Get a free .is-a.dev or .js.org via their GitHub-based programs
  3. For now (zero cost, zero setup): use the free yourname.github.io URL — what SONKA's web app uses today
Cost: $0 to ~$10/year · Time: 15 min

✅ Your $0 toolkit checklist

  • Claude Code installed and signed in
  • VS Code installed
  • GitHub account created (username noted)
  • Supabase project provisioned (password saved)
  • Railway account connected to GitHub
  • Higgsfield account (10 free credits)
  • Domain or github.io URL ready
